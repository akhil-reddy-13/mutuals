# Demo video

Draft cut: [`docs/video/mutuals-demo-draft.mp4`](video/mutuals-demo-draft.mp4) (3:04, 720p preview). The 1080p master
is regenerated by `scripts/video/record.mjs` into `scripts/video/out/mutuals-demo.mp4` (not committed).

Everything on the phone is the real app, and every model output is a real Muse response. Placeholders for the final cut:
the cold-open skit (shown as a storyboard; we film it live), the voices (macOS text-to-speech), and the room video
(Muse Image stills plus a text-to-speech narration instead of a real phone video).

## Story

Jamie, a Stanford '27 student, landed a summer SWE internship in Chicago (yes, McDonald's HQ) and knows nobody there.
Two things Facebook is already good for, with the awkward part handed to Muse:

1. **Find a room** in the Chicago Summer Interns 2027 Group. Jamie's Muse pre-negotiates with every member's Muse at
   once, reads posts from people without Muse, and comes back with a shortlist. Then it nudges Jamie and Nora toward a
   run club, because they have more in common than a lease.
2. **Sell the dorm stuff** in Stanford Free & For Sale. Jamie films the desk and talks. Ember watches and listens, Spark
   identifies each item and prices it, one tap lists it on Marketplace.

Then the daily digest: small asks worth answering (a skill swap, a plus one, a study partner).

## Making it

```bash
cd scripts/video && npm install && cd ../..        # once: puppeteer-core (drives your installed Chrome)
node scripts/video/gen-assets.mjs                   # once: desk stills (Muse Image) + room.mp4 (already committed)
NEXT_DIST_DIR=.next-demo npx next build             # production build: fast pages, no dev badge
NEXT_DIST_DIR=.next-demo MUSE_REPLAY_DELAY_MS=1300 npx next start -p 3001
node scripts/video/record.mjs --dry                 # runs every flow LIVE on Muse once and caches it (~2 min)
node scripts/video/record.mjs                       # records the take (~3 min) and mixes the voiceover
```

- `studio.html` is the 1920x1080 stage: the app in a phone frame (an iframe of `127.0.0.1:3001`), captions on the right,
  full-screen cards for the skit, title, stat and close. `record.mjs` taps and types in the app like a person, changes
  the captions, and logs when each voice line starts; ffmpeg mixes the lines onto the screen recording.
- Use `127.0.0.1`, not `localhost`: cookies ignore ports, so a dev server on `localhost:3000` would share the persona
  cookie with the recording.
- `MUSE_REPLAY_DELAY_MS` (new, default 0, `src/lib/muse.ts`) pauses on a cache hit so the negotiation streams in turn
  by turn as it did live, instead of all at once. Say so if asked: "recorded from a live run, replayed for the video".
- Debug one beat with `--only housing|selling|digest`; a failure saves `scripts/video/out/failed.png` and `failed.txt`.
- Changing anything that reaches a prompt (seed asks, typed lines, prompts.ts) means re-running `--dry` first.
